# 🩸 Stranger Things — Landing Page Interativa

Projeto de landing page interativa inspirado no universo da série **Stranger Things**, com foco em **imersão visual**, **animações suaves controladas pelo scroll** e **experiência cinematográfica** no desktop e mobile.

O objetivo principal do projeto é explorar animações avançadas com **GSAP**, **ScrollTrigger** e **ScrollSmoother**, mantendo uma estrutura de código organizada, performática e escalável.

A página foi prontamente criada e desenvolvida do zero no evento DevArt: Projetos de Alto valor do Desenvolvedor Gustavo Campelo, ao qual tem todos os direitos reservados.

---

## 🎯 Objetivo do Projeto

- Criar uma experiência visual imersiva
- Trabalhar animações sincronizadas com o scroll
- Explorar efeitos de texto com **SplitText**
- Aplicar boas práticas de animação e performance
- Desenvolver um projeto de portfólio com identidade própria

---

## 🚀 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **GSAP (GreenSock Animation Platform)**
  - ScrollTrigger
  - ScrollSmoother
  - SplitText

---

## ✨ Principais Funcionalidades

- 🎬 **Scroll suave (Smooth Scroll)** com GSAP ScrollSmoother
- 🧠 **Animações de texto controladas pelo scroll**
- 🩸 **Efeitos de entrada progressivos** (fade, blur, translate)
- 🖥️ **Layout responsivo** para desktop e mobile
- ⏳ **Preloader animado**
- 🎨 Identidade visual inspirada em Stranger Things
